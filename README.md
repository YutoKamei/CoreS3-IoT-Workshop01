# M5Stack CoreS3でIoTシステムを作ってみよう！

> 高校生向け研究室体験実習 | 温度測定 → サーバ送信 → スマートフォンで確認

## 今日のゴール

M5Stack CoreS3と温度センサを使って温度を測定し、Wi-Fiでサーバへ温度データを送信して、スマートフォンのWeb画面から確認します。

また、CoreS3に搭載されているディスプレイにも測定した温度を表示してみます。

さらに、今回の実習で体験したIoT技術が、実際の研究でどのように活用されているのかを学びます。

**初めてプログラミングする人も大丈夫です。** 各STEPには「基本課題」と、早く終わった人向けの「チャレンジ課題」があります。

困ったら担当者に聞いてください。

## どんな仕組み？

```text
温度センサ（DS18B20）
       ↓ 温度を測定
M5Stack CoreS3
       ├── 本体ディスプレイに温度を表示
       │
       └── Wi-Fiで温度データを送信
                   ↓
                 サーバ
                   ↓
              スマートフォン
```

- **温度センサ**：現実世界の温度を測定する部品。
- **M5Stack CoreS3**：センサの値を読み取り、画面表示や通信を行う小さなコンピュータ。
- **サーバ**：送られたデータを受け取り保存するコンピュータ。
- **IoT**：モノをネットワークにつないで、データを活用する仕組み。

## 今日の約束

1. 配線は **USBケーブルを外した状態** で行います。
2. CoreS3本体や接続部分を水でぬらさないようにしましょう。
3. 配線が終わったら、電源を入れる前に講師に確認してもらいましょう。
4. 途中でつまずいたら、無理に進めず担当者と確認します。
