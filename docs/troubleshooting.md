# 困ったときのチェックリスト

[🏠 トップ](../README.md) | [事前準備](00-setup.md) | [STEP 1](01-temperature.md) | [STEP 2](02-server.md) | [STEP 3](03-smartphone.md)

このページは、**M5Stack CoreS3 + DS18B20 + AWS IoT Core** を使う実習のトラブル対処方法をまとめたものです。

困ったときは、**①何をしようとしたか → ②何が起こったか → ③画面やシリアルモニタに何と表示されたか** を確認しましょう。

解決しない場合は、無理に操作を続けず講師に相談してください。

> [!IMPORTANT]
> **配線を直すときは電源を切り、USBケーブルを外してください。**
>
> また、CoreS3本体・ケーブルの接続部を水でぬらさないでください。

## 1. Arduino IDEでCoreS3が認識されない・書き込めない

- USBケーブルは **USB Type-Cのデータ通信対応** ですか？ 充電専用ケーブルではプログラムを書き込めません。
- Arduino IDEの **ボード** に `M5CoreS3` を選択していますか？
- **ツール → ポート** でCoreS3が接続されたポートを選択していますか？ ポート番号はPCによって異なります。
- USBケーブルを差し直したときに、選択できるポートが変わるか確認しましょう。
- 別のアプリがポートを使用していないか確認しましょう。必要に応じてシリアルモニタを閉じ、再度書き込んでください。
- 画面下部のコンパイル・書き込みエラーを確認しましょう。

> [!NOTE]
> ボードが選択肢に表示されない場合は、CoreS3に対応するボードパッケージの設定が必要です。
>
> 研修用PCでは講師が事前に準備しています。
>
> 書き込みモードへの切り替えが必要な場合は、**講師の指示に従って**操作してください。無理にボタンを押したり、分解したりしないでください。
>
> 📖 [M5Stack CoreS3 Arduino開発手順（公式）](https://docs.m5stack.com/en/arduino/m5cores3/program)

## 2. ライブラリが見つからず、コンパイルできない

次のようなエラーが表示される場合は、必要なライブラリが入っているか確認しましょう。

```text
M5Unified.h: No such file or directory
OneWire.h: No such file or directory
DallasTemperature.h: No such file or directory
```

Arduino IDEの **ライブラリマネージャー** で、次の3つを確認します。

| ライブラリ | 役割 |
| --- | --- |
| `M5Unified` | CoreS3のディスプレイなどを操作する |
| `OneWire` | DS18B20と通信する |
| `DallasTemperature` | 温度を読み取る |

研修ではインストール済みの想定です。見つからない場合は講師に相談してください。

## 3. 温度が表示されない・`Sensor Error` が出る

まず、**CoreS3のディスプレイとArduino IDEのシリアルモニタの両方**を確認しましょう。シリアルモニタの通信速度は **115200 baud** に設定します。

### 配線を確認する

**USBケーブルを外してから**、次の項目を確認してください。

- Groveケーブルを、実習で指定した **PORT.B** に接続していますか？
- DS18B20の **DQがGPIO8** に接続されていますか？
- DS18B20の **VDDは5V、GNDはGND** に接続されていますか？
- DS18B20の **VDD / DQ / GND** をデータシートで確認しましたか？ 配線色だけで判断しないでください。

### エラー表示を確認する

- `Sensor Error` や `DISCONNECTED` と表示される場合は、センサが読み取れていない可能性があります。
- シリアルモニタに `-127` ℃程度が表示される場合は、DS18B20を検出できていない可能性があります。
- センサの接続を確認しても改善しない場合は、講師に相談してください。

## 4. CoreS3の画面に何も表示されない・表示が更新されない

- STEP 1またはSTEP 2の **CoreS3用プログラム** を書き込みましたか？
- プログラムの書き込みが正常に完了していますか？
- 温度がシリアルモニタには表示されていますか？
- 画面は点灯していますか？ 異常な発熱やにおいがある場合はすぐに使用を中止し、講師に知らせてください。

シリアルモニタには温度が表示されているのに画面だけ更新されない場合は、**画面描画処理**の問題である可能性があります。変更したコードを講師と確認しましょう。

## 5. Wi-Fiにつながらない

- 講師が指定した **2.4GHz帯のWi-Fi** を使用していますか？
- 講師から受け取った **`secrets.h`** を、Arduinoスケッチ（`.ino`）と同じフォルダに配置していますか？
- Wi-FiのSSIDとパスワードは、講師が配布した設定になっていますか？
- CoreS3がアクセスポイントから離れすぎていませんか？
- ブラウザでログインが必要なWi-Fiなど、特殊な接続方式になっていませんか？

> [!NOTE]
> GitHubに置かれている **[`secrets_sample.h`](../code/step2/secrets_sample.h)** は、設定内容を学ぶためのサンプルです。空欄のままではWi-FiやAWS IoT Coreへ接続できません。
>
> 実際の通信には、講師がPCへ直接配布した **`secrets.h`** を使用します。

## 6. AWS IoT Coreへ接続できない

Wi-Fiには接続できるのにAWS IoT Coreへ接続できない場合は、次の点を確認します。

- `secrets.h` が正しいフォルダにあり、プログラムを読み込めていますか？
- 使用している `secrets.h` は、**自分のCoreS3用**として講師から渡されたものですか？
- `AWS_IOT_ENDPOINT`、`AWS_IOT_CLIENT_ID` などの設定が講師の指定どおりですか？
- 同じMQTTクライアントIDを、別のCoreS3と同時に使っていませんか？
- シリアルモニタに接続エラーが表示されていませんか？

AWS IoT Coreでは、**証明書と秘密鍵を使用して通信相手を認証**します。

また、TLS通信ではCoreS3の時計が正しく設定されていることも重要です。

Wi-Fi接続後に時刻同期ができていない場合や、研修用ネットワークから **TCPポート8883** に接続できない場合は、講師に相談してください。

> [!IMPORTANT]
> `secrets.h` にはWi-FiパスワードやAWSの秘密鍵などが含まれます。
>
> **GitHub、SNS、チャット、画面写真、発表資料などに、その中身を公開しないでください。**
>
> 調査のために画面を見せる場合も、認証情報が表示されていないことを確認しましょう。

## 7. 温度データをAWS IoT Coreへ送信できない

- **温度測定**が正常にできていますか？
- **Wi-Fi接続**と**AWS IoT CoreへのMQTT接続**は成功していますか？
- 講師から指定された **MQTTトピック** に送信する設定ですか？
- シリアルモニタに送信メッセージ（例：`Published: ...`）やエラーが表示されていませんか？
- STEP 2で指定されたプログラムを使用していますか？

> [!NOTE]
> CoreS3側で送信処理が成功したように見えても、**AWS IoT Coreで受信されたことや、データベースへ保存されたことまでは保証されません。**
>
> 講師にAWS IoT Core側の受信状況を確認してもらいましょう。

## 8. スマートフォンで温度が見えない・グラフが更新されない

- 講師が案内した **研修用Webページ** を開いていますか？
- 自分のCoreS3に対応する **デバイス名・識別番号** を選択していますか？
- CoreS3本体のディスプレイでは温度を確認できますか？
- STEP 2で、AWS IoT Coreへの送信が成功していますか？
- Web画面の **最終更新時刻** は新しいですか？
- Web画面が自動更新されない場合は、講師の指示に従って更新してください。

> [!TIP]
> CoreS3は約1秒ごとに温度を測定しても、AWS IoT Coreへの送信は約5秒ごとです。
>
> さらにWeb画面の更新間隔もあるため、**CoreS3とスマートフォンの表示が一時的に異なる**ことがあります。
>
> ※測定・送信間隔はSTEP 2のプログラム設定に従います。

## 9. 講師に相談するときに伝えること

1. 取り組んでいるSTEP（例：STEP 1 温度測定、STEP 2 AWS送信）
2. 何をしようとして、どのような問題が起きたか
3. CoreS3の画面やシリアルモニタのエラーメッセージ（**秘密情報は伏せる**）
4. 直前に変更したプログラムや配線
5. すでに試した対処方法
