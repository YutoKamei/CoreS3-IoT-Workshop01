## このページの目標

実習で使う機材と開発環境を確認し、M5Stack CoreS3にプログラムを書き込める状態にします。

> [!NOTE]
> **実習で使用する機材は、すべてこちらで用意しています。**
>
> 自分で購入する必要はありません。
>
> このページでは、研修後も自分で電子工作に挑戦したい人に向けて、各部品の購入先も紹介しています。

## 1. 必要なもの

今回の実習では、以下の機材を使用します。

| 機材 | 役割 |
| --- | --- |
| M5Stack CoreS3 | 温度を読み取り、画面表示やサーバへのデータ送信を行う |
| DS18B20（温度センサ） | 温度を測る |
| Grove接続ケーブル | CoreS3と温度センサを接続する |
| USB Type-Cデータ通信ケーブル | CoreS3とPCを接続する |
| Arduino IDEが使えるPC | プログラムを編集して書き込む |
| スマートフォン | Web画面でデータを見る |

### M5Stack CoreS3とは？

M5Stack CoreS3は、ESP32-S3というマイコンを搭載した開発デバイスです。

一般的なESP32開発ボードとは異なり、ディスプレイやタッチパネルなどの機能が搭載されています。

今回の実習では、次の機能を使用します。

- **温度測定**：DS18B20から温度データを取得する
- **画面表示**：測定した温度をCoreS3のディスプレイに表示する
- **Wi-Fi通信**：測定データをサーバへ送信する

詳しい仕様は、以下の公式ドキュメントで確認できます。

📖 **[M5Stack CoreS3公式ドキュメント](https://docs.m5stack.com/ja/core/CoreS3)**

> [!IMPORTANT]
> **温度センサの端子について**
>
> センサの配線色は製品によって異なります。
> 色だけで判断せず、使用する製品の**VDD / DQ / GND** の説明を確認しましょう。

## 3. Arduino IDEを開く

Arduino IDEは、マイコン用プログラムを作成して書き込むためのソフトです。

今回は、このソフトを使ってESP32にプログラムを書き込みます。

### 3-1. Arduino IDEを起動する

1. PCで **Arduino IDE** を開きます。
2. CoreS3をUSB Type-CケーブルでPCに接続します。
3. **ツール → ボード** から使用するCoreS3に対応するボードを選択します（例：**M5CoreS3**。講師指定があればそれに従う）。
4. **ツール → ポート** から接続したCoreS3のポートを選択します。
5. ポートが表示されなければ、USBケーブルやドライバーを担当者と確認しましょう。

> [!NOTE]
> **ボードとポートの選択について**
>
> CoreS3では、ボードとして **M5CoreS3** を選択します。
>
> ポート番号（COM4など）は使用するパソコンによって異なります。
> 自分のパソコンに表示されたポートを選択してください。

### 3-2. M5Stack CoreS3のボード設定について

Arduino IDEでM5Stack CoreS3を使用するには、M5Stack CoreS3用のボードパッケージが必要です。

研修では、あらかじめ講師側でインストールしています。

自宅のPCなどで開発する場合は、以下の公式ページなどを参考に設定してください。

📖 **[M5Stack CoreS3公式インストール手順（Espressif Systems）](https://docs.espressif.com/projects/arduino-esp32/en/latest/installing.html)**

Arduino IDEのボードマネージャーで**esp32 by Espressif Systems** をインストールします。

> [!NOTE]
> **プログラムを書き込めない場合**
>
> CoreS3が正常に認識されない場合や、書き込みに失敗する場合があります。
>
> その場合は、USBケーブル・ポート・ボード設定を確認し、講師に相談してください。

## 4. ライブラリを確認する

**ライブラリ** は、プログラムで使える便利な機能をまとめたものです。

今回の実習では、温度センサやCoreS3のディスプレイを扱うため、以下の3つを使用します。

| ライブラリ名 | 役割 |
| --- | --- |
| `OneWire` | DS18B20との通信に使用する |
| `DallasTemperature` | DS18B20から温度を取得する |
| `M5Unified` | CoreS3のディスプレイなどを制御する |

実習では講師側でインストール済みなので、基本的には追加作業は不要です。

自宅でインストールする場合は、Arduino IDEのライブラリマネージャーで各ライブラリ名を検索してください。

📖 **[M5Stackライブラリ導入手順（外部サイト）](https://docs.sunfounder.com/projects/elite-explorer-kit/ja/latest/arduino_start/09_add_lib.html)**
